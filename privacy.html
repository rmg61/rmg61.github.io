Privacy policy

7InchDesktopDisplay is a personal desk display used only by its owner. This policy explains how it handles Google user data.

What it accesses

  • Google Calendar (read-only): event titles, times and locations, to show upcoming appointments and a month calendar. Event descriptions are not read.
  • Gmail: inbox messages (sender, subject, date, text) so the owner can read them on the display; and, only when the owner taps the corresponding button, moving a message to Trash (and back) or marking it read/unread. The app never sends email.

How it is stored and shared

  • Data is fetched by a small program running on the owner's own computer and shown on the owner's display on the same home network. It is kept in memory only for display and is not stored elsewhere.
  • No data is sold, shared with third parties, used for advertising, or used to train any model.
  • The sign-in token is stored only on the owner's computer.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
